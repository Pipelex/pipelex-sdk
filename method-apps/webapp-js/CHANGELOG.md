# Changelog

This template is released as part of the method-app family, `method-apps/` in the `Pipelex/pipelex-sdk` repository, which carries one version for every template, so its history is the family's changelog, [`method-apps/CHANGELOG.md`](https://github.com/Pipelex/pipelex-sdk/blob/main/method-apps/CHANGELOG.md).

A project created from this directory starts its own history here: the bootstrap replaces this file with the project's first entry.
